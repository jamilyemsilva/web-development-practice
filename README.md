# Web Development Practice

Repositório dedicado à prática e ao aprendizado de desenvolvimento web por meio de pequenos projetos desenvolvidos com HTML5, CSS3 e JavaScript.

O objetivo é consolidar os fundamentos da criação de interfaces web, praticando estruturação de páginas, estilização, layouts responsivos e interatividade.

## 🎯 Objetivos de aprendizagem

- Praticar a estruturação semântica com HTML5.
- Desenvolver interfaces com CSS3.
- Compreender e aplicar Flexbox e CSS Grid.
- Criar layouts responsivos para diferentes tamanhos de tela.
- Desenvolver funcionalidades com JavaScript.
- Praticar manipulação do DOM, eventos e validação de formulários.
- Melhorar a organização, legibilidade e manutenção do código.
- Utilizar Git e GitHub para versionamento e acompanhamento da evolução dos projetos.

## 🛠️ Tecnologias

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- JavaScript
- Git e GitHub
